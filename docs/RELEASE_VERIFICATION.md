## チェック方法

- ❌ の場合は事象と対応を残す
- 検証完了後、本ファイルの末尾にコミットする

### 1. 新規メンバー招待〜LINEログインフロー

**前提**: 管理者がテスト用LINEアカウント向けに招待リンクを発行できる状態

| # | 手順 | 期待結果 |
|---|---|---|
| 1.1 | 管理者でログインし、テスト用仮アカウントを作成して招待リンク発行 | 招待リンクURLが取得できる |
| 1.2 | テスト端末（Safari, 別LINEアカウント）でCookieをクリア | クリーンな状態 |
| 1.3 | テスト端末で招待リンクを開く | `/invite/complete?token=...` → ログインページへリダイレクト |
| 1.4 | LINEでログインを押し、LINE認証を完了 | アプリトップに到達、メンバーとして登録完了 |
| 1.5 | DB の `User` テーブルを確認 | 新メンバー行で `lineId = U...`, `profileImageUrl = LINE画像URL` がセット |
| 1.6 | 管理画面のメンバー一覧を確認 | 新メンバーにLINEアイコンが表示される |

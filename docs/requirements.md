# 283バドミントン 出欠管理アプリ 機能要件書

最終更新: 2026-05-06（代理出欠登録・メンバー削除追加）

---

## 1. 概要

バドミントンサークル「283」向けの出欠・メンバー管理Webアプリ。LINEアカウントで認証し、イベントへの参加・不参加を管理する。

---

## 2. 技術スタック

| 項目 | 内容 |
|------|------|
| フレームワーク | Next.js 16 (App Router) |
| 言語 | TypeScript |
| ORM | Prisma 5 |
| DB (ローカル) | SQLite |
| DB (DEV/本番) | Azure SQL Database |
| 認証 | NextAuth.js v4（LINE OAuth） |
| インフラ | Azure App Service |
| CI/CD | GitHub Actions |

---

## 3. ロール定義

| ロール | 名称 | 説明 |
|--------|------|------|
| `admin` | 管理者 | 全機能にアクセス可能 |
| `subadmin` | 副管理者 | 管理画面・イベント作成が可能 |
| `member` | 一般 | 出欠登録・メンバー閲覧が可能 |
| `visitor` | ビジター | 管理者が作成した仮アカウント。招待完了後にmemberへ昇格 |
| `guest` | ゲスト | LINEログインのみ完了した未招待ユーザー |

### ロール別権限

| 機能 | guest | visitor | member | subadmin | admin |
|------|:-----:|:-------:|:------:|:--------:|:-----:|
| イベント閲覧 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 出欠登録 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 参加者リスト閲覧 | - | - | ✓ | ✓ | ✓ |
| メンバー詳細閲覧 | - | - | ✓ | ✓ | ✓ |
| イベント作成・編集・削除 | - | - | - | ✓ | ✓ |
| 管理画面アクセス | - | - | - | ✓ | ✓ |

---

## 4. 認証

- **LINEログイン**による認証（NextAuth.js + LINE OAuth 2.0）
- セッション戦略: JWT
- 新規LINEログインユーザーは `guest` ロールで作成される
- ローカル開発環境のみ: CredentialsProviderによるテストログイン（User IDを直接入力）

---

## 5. 画面・機能一覧

### 5.1 ホーム (`/`)
- 直近イベントの一覧表示（今後7日間）
- 自分の出欠状況表示
- 未ログイン時はログインページへリダイレクト

### 5.2 ログイン (`/login`)
- LINEログインボタン
- 開発環境のみ: User IDによるテストログイン

### 5.3 イベント一覧 (`/events`)
- 全イベントの一覧表示
- 開催日時・場所・定員・自分の出欠状況を表示
- subadmin以上: イベント作成ボタン

### 5.4 イベント詳細 (`/events/[eventId]`)
- イベント情報の詳細表示
- 出欠登録（参加/不参加）
- キャンセル待ち（定員超過時）
- member以上: 参加者リスト閲覧
- subadmin以上: イベント編集・削除

### 5.5 イベント作成 (`/events/new`)
- subadmin以上のみアクセス可
- 設定項目: タイトル、説明、開催日時、終了日時（任意）、場所、定員、参加費、締め切り

### 5.6 イベント編集 (`/events/[eventId]/edit`)
- subadmin以上のみアクセス可

### 5.7 メンバー一覧 (`/members`)
- 全メンバーの一覧表示
- member以上: 詳細情報（スキルレベルなど）表示

### 5.8 プロフィール編集 (`/profile`)
- 自分のニックネーム・性別・年齢・コメントを編集
- 年齢の公開/非公開設定

### 5.9 管理トップ (`/admin`)
- subadmin以上のみアクセス可
- メンバー管理・履歴へのリンク

### 5.10 メンバー管理一覧 (`/admin/members`)
- 全メンバーの一覧（ロール・スキルレベル・最終操作日時）
- **仮アカウント作成**: ニックネームを入力してvisitorロールのアカウントを即時作成

### 5.11 メンバー詳細 (`/admin/members/[userId]`)
- メンバー情報の閲覧・編集（ニックネーム・姓名・性別・年齢・コメント・ロール）
- 管理者専用情報の編集（スキルレベル・管理者メモ）
- **招待リンク管理**（visitorロールのみ表示）
  - 招待URL発行（有効期限3日間）
  - 再発行・無効化
  - URLコピー
- **代理出欠登録**（全ロール対象）
  - 直近10件のイベントと現在の出欠状況（参加/不参加/未登録）を表示
  - 参加・不参加ボタンで選択後、「確定」ボタンで送信（2ステップ）
  - 現在値と同じ選択では確定ボタンが無効
- **メンバー削除**（自分自身は削除不可）

### 5.12 出欠履歴 (`/admin/history`)
- subadmin以上のみアクセス可
- 出欠変更の履歴一覧
- 管理者による代理登録はオレンジ背景＋「管理者代理登録」バッジで識別

## 6. 仮アカウント・招待フロー

### 6.1 フロー概要

```
管理者 → 仮アカウント作成(visitor) → 招待URL発行 → 対象者に送付
→ 対象者がURLをブラウザで開く → LINEログイン → アカウントマージ → member昇格
```

### 6.2 仮アカウント作成
- 管理者が `/admin/members` からニックネームを入力して作成
- `visitor` ロールで作成
- lineId・email未設定の状態

### 6.3 招待URL
- `/invite/[token]` 形式
- トークンはCUID、DB管理（InvitationTokenテーブル）
- 有効期限: 発行から**3日間**
- 再発行すると旧トークンは無効化
- 管理者が手動で無効化も可能

### 6.4 招待ページ (`/invite/[token]`)
- トークンの有効性を確認し、対象者名を表示
- **LINE IAB（LINEアプリ内ブラウザ）検出**: LINE内でURLを踏んだ場合は外部ブラウザで開くよう誘導（iOS: 右下「...」→「ブラウザで開く」、Android: 右上「⋮」→「他のアプリで開く」）
- 既にログイン済みの場合: そのアカウントで参加するフローへ
- 未ログインの場合: LINEログインへ誘導

### 6.5 アカウントマージ (`/invite/complete`)
- LINE認証完了後に自動実行
- 仮アカウントの以下のデータをLINEアカウントに引き継ぎ:
  - ロール（visitorの場合は**memberに自動昇格**）
  - プロフィール情報（ニックネーム・姓名・性別・年齢・コメント・スキルレベル・管理者メモ）
  - 出欠データ（イベント重複時は仮アカウント側を優先）
  - 出欠変更履歴
- マージ完了後、仮アカウントは削除

## 7. データモデル（主要テーブル）

### User
| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | String | CUID（PK） |
| lineId | String? | LINE User ID（unique、nullは除外） |
| email | String? | メール（unique、nullは除外） |
| nickname | String | ニックネーム |
| firstName / lastName | String? | 氏名（非公開） |
| gender | String? | 性別: male / female |
| age | Int? | 年齢 |
| ageVisible | Boolean | 年齢公開設定 |
| role | String | admin / subadmin / member / visitor / guest |
| skillLevel | Int? | スキルレベル 1〜10（管理者専用） |
| adminNote | String? | 管理者メモ（管理者専用） |
| lastActiveAt | DateTime? | 最終操作日時 |

### Event
- タイトル・説明・開催日時・終了日時・場所・定員・参加費・締め切り

### Attendance
- ユーザー×イベントの出欠（attending / not_attending / waitlist）
- キャンセル待ち順（position）

### AttendanceHistory
- 出欠変更のたびに記録
- `isProxy Boolean` : 管理者代理登録かどうかのフラグ

### InvitationToken
- 招待トークン・有効期限・ユーザーへの紐づけ

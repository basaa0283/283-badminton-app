# パイロットサークル受け入れガイド (運営者用)

知人サークルを complimentary プラン (全機能無料) で受け入れる際の手順。
2026-09-15 時点の運用 (通知・LINE チャネル方針の決定を反映)。

## 方針 (2026-09-15 決定)

- **認証**: 全テナント共通の LINE チャネル (env 設定) を使う。**先方の LINE Developers 作業は不要**
- **通知**: 他サークルは**メール通知のみ**。LINE Push 通知は 28ばど 専用
- テナント別 LINE チャネル (/platform の「LINE設定」) は将来の上級オプション。通常は使わない

## 受け入れの流れ

1. 【先方 or 運営】サークル情報を申請する
   - 先方に `/apply` から申請してもらう、または運営が `/platform` の「新規テナント作成」で直接作る
2. 【運営】`/platform` で申請を承認 (slug 確定) → テナント作成 (plan は complimentary に)
3. 【先方代表】サークルの URL (`https://<アプリのドメイン>/<slug>`) にアクセスして LINE ログイン
   - 初回ログイン時、そのテナントの Membership が pending で作られる
4. 【運営】先方代表を admin に昇格 (テナント URL 配下のメンバー管理から)
5. 【先方】メンバーに URL を展開して利用開始。以降の承認・運営は先方 admin が行う

## 先方への案内テンプレ

> サークル管理アプリのご利用準備ができました！
>
> 1. こちらの URL を開いて LINE でログインしてください:
>    `https://<アプリのドメイン>/<サークルID>`
> 2. ログインできたら教えてください。管理者権限を付与します
> 3. その後はメンバーの皆さんに同じ URL を共有して、参加申請 → あなたが承認、の流れで使えます
>
> 通知はメールで受け取れます (プロフィール画面からメールアドレスを登録)。
> 出欠管理・イベント作成・お知らせなどは全機能そのまま使えます。

## 運営側の注意点

- パイロットのプランは `complimentary` (全機能無料) にする (`/platform` で切替)
- LINE Push 通知は他テナントには届かない仕様 (メール通知を案内する)
- **既知の制約**: リマインダーの自動配信 (cron) は現状 28ばど のイベントのみ対象。
  他テナント向けメールリマインダーの対応は P5 で実装予定 → それまでは
  「リマインダーは届かない」旨を先方に伝えておく
- SystemSetting (公式 LINE URL 等) はまだグローバル 1 セットのため、テナント別設定は未対応
